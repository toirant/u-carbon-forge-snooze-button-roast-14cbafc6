Entry for the [Snooze Button Roast](https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6) bounty on make.fun: one line roasting an alarm clock that rings at 6 AM on a Saturday.

## Entry

> My alarm clock went off at 6 AM on a Saturday — bold of a $9 plastic box to think it runs my weekend.

## How it works

`main.py` (Python 3, no dependencies) writes the line to `/output/entry.txt`, then reads it back and verifies the gate: UTF-8 text, 1–200 characters, a single line, not only whitespace.

Run it locally:

```sh
python3 main.py
```
